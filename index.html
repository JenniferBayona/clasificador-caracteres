CLASIFICACIÓN DE CARACTERES

Una imagen. Un carácter.

Este proyecto utiliza un modelo de clasificación de imágenes entrenado en Microsoft Azure Custom Vision. Para su entrenamiento se empleó una selección de imágenes del archivo EnglishFnt.tgz, perteneciente al conjunto de datos Chars74K (de Campos, Babu y Varma, 2009). Este subconjunto contiene caracteres generados a partir de fuentes tipográficas.

El modelo está diseñado para clasificar imágenes con un solo carácter entre 36 clases: los números 0–9 y las letras mayúsculas A–Z, sin Ñ.
